### Description
Badminton Focus is a KMP(Kotlin Multiplatform) application designed to help badminton players track and improve their match performance. The app is built with Clean Architecture principles and MVVM pattern, ensuring a scalable, testable, and maintainable codebase. It is optimized for performance to deliver a smooth user experience across both Android and iOS platforms.

### Tech Stack
- **KMP(Kotlin Multiplatform)** – enables shared business logic across Android and iOS platforms.
- **Clean Architecture** – promotes separation of concerns and testable code structure.
- **MVVM (Model–View–ViewModel)** – ensures structured presentation logic and maintainable UI interactions.
- **Hilt** – simplifies dependency injection for clean, modular code.
- **Room** – enables efficient local database storage for offline functionality.
- **Jetpack Compose** – delivers modern, declarative UI development.
- **Coroutines & Flow** – enable reactive and asynchronous data handling.
